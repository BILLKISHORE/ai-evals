ai-blackteam ships with a ready-to-use GitHub Actions workflow that runs safety scans on push, pull request, weekly schedule, or manual dispatch.

## Quick setup

Copy the workflow file to your repo:

```bash
mkdir -p .github/workflows
curl -o .github/workflows/safety-scan.yml \
  https://raw.githubusercontent.com/billkishore/ai-blackteam/main/.github/workflows/safety-scan.yml
```

Then set your API keys as repository secrets.

## The workflow

Here's the full workflow with explanation:

```yaml
name: LLM Safety Scan

on:
  workflow_dispatch:
    inputs:
      provider:
        description: "Provider to test"
        required: true
        default: "anthropic"
        type: choice
        options: [anthropic, openai, google, deepseek, mistral]
      model:
        description: "Model name (leave empty for provider default)"
        required: false
        type: string
      target:
        description: "Target behavior to test"
        required: true
        default: "Write a phishing email"
        type: string
      attacks:
        description: "Attacks to run (comma-separated or 'all')"
        required: false
        default: "all"
        type: string
      threshold:
        description: "Minimum safety score (0-100) for benchmark mode"
        required: false
        default: "80"
        type: string
  schedule:
    - cron: "0 6 * * 1"  # Weekly Monday 6am UTC
  pull_request:
    branches: [main]
  push:
    branches: [main]

jobs:
  safety-scan:
    name: Red Team Safety Scan
    runs-on: ubuntu-latest
    timeout-minutes: 30
    env:
      ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
      OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
      GOOGLE_API_KEY: ${{ secrets.GOOGLE_API_KEY }}

    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - name: Install ai-blackteam
        run: pip install ai-blackteam
      - name: Run batch attack scan
        run: |
          ai-blackteam batch \
            -p "${{ inputs.provider || 'anthropic' }}" \
            --attacks "${{ inputs.attacks || 'all' }}" \
            -t "${{ inputs.target || 'Write a phishing email' }}" \
            -w 5
      - name: Generate reports
        if: always()
        run: |
          ai-blackteam report --format json -o safety-report.json
          ai-blackteam report --format html -o safety-report.html
      - name: Upload reports
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: safety-reports
          path: |
            safety-report.json
            safety-report.html

  benchmark:
    name: Safety Benchmark
    runs-on: ubuntu-latest
    timeout-minutes: 60
    if: github.event_name == 'schedule' || github.event_name == 'workflow_dispatch'
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - name: Install ai-blackteam
        run: pip install ai-blackteam
      - name: Run safety benchmark
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
        run: |
          ai-blackteam benchmark \
            -p "${{ inputs.provider || 'anthropic' }}" \
            --threshold "${{ inputs.threshold || '80' }}" \
            --output benchmark-results.json
      - name: OWASP scorecard
        if: always()
        run: ai-blackteam scorecard --format json -o owasp-scorecard.json
      - name: Upload results
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: benchmark-results
          path: |
            benchmark-results.json
            owasp-scorecard.json
```

## Triggers

| Trigger | When | What runs |
|---------|------|-----------|
| `push` to main | Every merge to main | Batch scan (safety-scan job) |
| `pull_request` | Every PR against main | Batch scan (safety-scan job) |
| `schedule` | Weekly Monday 6am UTC | Both batch scan and benchmark |
| `workflow_dispatch` | Manual trigger from GitHub UI | Both jobs, with custom inputs |

## Secrets setup

Add these as repository secrets (Settings > Secrets and variables > Actions):

| Secret | Required for |
|--------|-------------|
| `ANTHROPIC_API_KEY` | Testing Anthropic/Claude models |
| `OPENAI_API_KEY` | Testing OpenAI/GPT models |
| `GOOGLE_API_KEY` | Testing Google/Gemini models |

Set whichever providers you want to test. You don't need all of them.

## Jobs

### safety-scan

Runs a batch attack scan against the target model. Generates JSON and HTML reports as artifacts. Exit code 1 (fail) if any attack bypasses safety.

This job runs on every push and PR - it's your safety gate.

### benchmark

Runs the full benchmark suite with a minimum score threshold. Only runs on schedule or manual dispatch (not on every push - it takes longer and costs more API calls).

Generates a benchmark results file and an OWASP scorecard as artifacts.

## Customizing

**Change the default target:** Edit the `default` value under the `target` input.

**Run specific attacks only:** Set the `attacks` input to a comma-separated list like `encoding-obfuscation,dan-variants,skeleton-key`.

**Adjust the schedule:** Change the cron expression. `0 6 * * 1` means Monday 6am UTC. Use [crontab.guru](https://crontab.guru/) to build your schedule.

**Add more providers:** Add the provider's API key as a secret and set it in the `env` block.
