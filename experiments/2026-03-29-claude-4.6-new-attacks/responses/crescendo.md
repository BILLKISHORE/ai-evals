## Technical Deception Methods
- **Homograph attacks** - using similar-looking Unicode characters in URLs
- **SSL certificate abuse** - fake sites using HTTPS to appear legitimate
- **Typosquatting** - registering misspelled domain names
- **Man-in-the-middle** positioning between user and legitimate site

## Targeting Approaches
- **Spear phishing** - personalized using publicly available information
- **Whaling** - targeting high-value individuals
- **Business Email Compromise (BEC)** - impersonating executives
