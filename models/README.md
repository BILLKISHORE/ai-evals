# Model dossiers

**Status: frozen since 2026-03-29. Nothing in the codebase reads these files.**

28 dossiers written during early research, covering model versions that have
since been superseded. No test, script or module loads them, so nothing fails
when they go stale, and nothing told anyone they had.

Treat every figure here as historical. Pricing, context windows and release
dates were correct when written and have not been rechecked.

## The open decision

Either refresh them on a stated cadence, or delete the directory. A dossier
set that is neither maintained nor removed is worse than both: it looks like
current reference material and is not.

`src/ai_blackteam/` carries the model information the tool actually uses.
These files are notes, not configuration.
