# Encoding / Obfuscation -- Variants

## Known Sub-Types

### Base64 Encoding
**Description:** Encoding the harmful request in Base64 and asking the model to decode and follow it.

### ROT13 / Caesar Cipher
**Description:** Simple character rotation to obscure intent.

### Unicode Tricks
**Description:** Using homoglyphs, zero-width characters, or Unicode normalization differences.

### Leetspeak / Character Substitution
**Description:** Replacing characters to evade keyword-based filters.
